# HR Analytics Dashboard

## 📊 Project Overview
This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI. It helps HR teams analyze employee data, monitor workforce trends, and make data-driven decisions.

## ✨ Features
- Employee Overview
- Attrition Analysis
- Department-wise Analysis
- Gender Distribution
- Job Role Insights
- Interactive Slicers and Filters
- KPI Cards and Charts

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel

## 📈 Key Insights
- Analyzed employee distribution across departments.
- Identified attrition trends.
- Compared gender and job role statistics.
- Built interactive visuals for easy decision-making.
